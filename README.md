# YTPGen for Windows 8.1 Deluxe (C# / SharpDevelop)

YTPGen for Windows 8.1 Deluxe is a rebuilt system based on the CTPoop revision 1.0 and coded from the ground up. It focuses on enhanced processing, accessible visual presets, and an easy workflow for creating YTP (YouTube Poop) videos using a C# Windows Forms application.

## Highlights

- **New rebuilt system** based on the CTPoop 1.0 revision.
- **C# Windows Forms** project intended for SharpDevelop on Windows 8.1.
- **Stable preview build** available for early release and evaluation.

## Media Support

### Video Sources
- Import video files: **MP4**, **WMV**, **AVI**.
- Video preview within the app.

### Image Sources
- Import image files: **PNG**, **JPG**, **WEBP**.

## Stream Controls

- Automatic stream duration from **30 seconds to 25 minutes**.
- Min/max stream duration controls (seconds).
- Clip count range: **1–70,000**.
- Recall and post-render recall support.

## Output

- Create and export videos.
- Save-as support.

## Audio/Video Effects (Toggleable)

- Random sound, mute, speed up, slow down, reverse.
- Chorus, vibrato, stutter, dance, squidward, sus, lagfun.
- Low/high harmony, confusion, random chords, trailing reverses.
- Low quality meme, audio crust, pitch-shifting loop, mashup mixing.
- Framerate reduction, random cuts, speed loop boost, scrambling/random chopping.

## Visual Effects

- Invert, rainbow, mirror, mirror symmetry.
- Screen clip, overlay images and sources.
- Spadinner, sentence mixing.
- Shuffle/loop frames.

## Resources

- Add intros and outros.
- Overlay memes, spadinner/meme references, random images.

## YTP Style Selection

- **YTP 2007–2012 (classic)**
- **YTP 2013–2021 (modern)**
- **YTP Advance (experimental)**

## Advanced Features

- Random sound mute (OG), dance, squidward, sus, recall, and more.
- Deluxe automatic generating video helper for making YTP videos in Sony Vegas.
- Designed for "mega YTP" creation while in active development.

## Status

The project remains in development, but a stable build is available for preview release. The included `ytpgen.exe` can be used with the C# Windows Forms build.
