# YTPGen for Windows 8.1 Deluxe (C# Forms)

YTPGen for Windows 8.1 Deluxe is a brand new, ground-up rebuild of YTPGen based on the CTPoop Revision 1.0 foundation. This project targets SharpDevelop Windows 8.1 C# Forms workflows and provides a stable preview build with the included `ytpgen.exe` for C# in the release.

## Overview

YTPGen for Windows 8.1 Deluxe is a deluxe automatic generating video helper for making YTP videos in Sony Vegas. It focuses on enhanced processing, accessible visual presets, easy making, and robust video/audio source support.

## Video & Audio Sources

- **Import video files:** MP4, WMV, AVI
- **Import image files:** PNG, JPG, WEBP
- **Video preview within the app**

## Flexible Stream Controls

- Automatic stream duration: **30 seconds – 25 minutes**
- Min/max stream duration (seconds)
- Clip count: **1 – 70,000**
- Recall and post-render recall

## Audio/Video Effects (Toggleable)

- Random sound, mute, speed up, slow down, reverse

- Low/high harmony, confusion, random chords, trailing reverses
