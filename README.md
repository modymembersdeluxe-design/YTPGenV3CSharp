# YTPGen Deluxe for Windows 8.1 (SharpDevelop C# Forms)

YTPGen Deluxe for Windows 8.1 is a rebuilt, ground-up system inspired by the CTPoop revision 1.0 lineage. This preview-ready build focuses on improved processing, accessible visual presets, and an easier creation flow for both video and audio content.

## Overview

- Built for Windows 8.1 using C# Forms (SharpDevelop).
- Includes **ytpgen.exe** for C# in the release build.
- Offers a streamlined automatic helper for generating YTP videos in Sony Vegas workflows.
- Stable preview release with ongoing development.

## Import & Source Support

- Video: MP4, WMV, AVI
- Images: PNG, JPG, WEBP
- In-app video preview

## Stream Controls

- Automatic stream duration: 30 seconds to 25 minutes
- Minimum/maximum stream duration (seconds)
- Clip count range: 1–70,000
- Recall and post-render recall
- Export & save generated videos

## Audio & Video Effects (Toggleable)

- Random sound, mute, speed up, slow down, reverse
- Chorus, vibrato, stutter, dance, squidward, sus, lagfun
- Low/high harmony, confusion, random chords, trailing reverses
- Low quality meme, audio crust, pitch-shifting loop, mashup mixing
- Framerate reduction, random cuts, speed loop boost, scrambling/random chopping

## Visual Effects

- Invert, rainbow, mirror, mirror symmetry, screen clip
- Overlay images and sources
- Spadinner, sentence mixing
- Shuffle/loop frames

## Resources & Style Selection

- Add intros and outros
- Overlay memes, spadinner/meme references, random images
- YTP style selection:
  - **YTP 2007–2012 (classic)**
  - **YTP 2013–2021 (modern)**
  - **YTP Advance (experimental)**

## Advanced Features

- Random sound mute (OG), dance, squidward, sus, recall, and more
- Deluxe automatic generating helper for mega YTP video creation

## Status

This project is in active development with a stable build ready for preview release.
